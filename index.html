AXI4-Lite Protocol Interface & Memory Controller

A synthesizable Verilog implementation of the AMBA AXI4-Lite protocol featuring an integrated Master initiator, 4-register Slave block, byte-strobe masking, and response status decoding.

View Source Code on GitHub

Core Technical Features

  • 5 Independent Handshake Channels: Full hardware support for AW, W, B, AR, and R channels with decoupled VALID / READY signaling.
  • Byte-Enable Strobes (WSTRB): Selective 8-bit byte writes over 32-bit registers.
  • Error Response Decoding (SLVERR): Generates 2'b10 protocol error codes for out-of-bounds address accesses beyond 0x0C.
  • Self-Checking Verification: Automated Verilog testbench validating write/read data integrity and handshake response timing.

System Architecture

 +---------------------+                       +---------------------+
 |                     |== Write Address =====>|                     |
 |  AXI4-Lite Master   |== Write Data =========>|  AXI4-Lite Slave    |
 |  (Initiator Core)   |<-- Write Response ----|  (4x32 Register)    |
 |                     |                       |                     |
 |                     |== Read Address ======>|  Byte Mask Logic    |
 |                     |<-- Read Data/Resp ----|  Error Handling     |
 +---------------------+                       +---------------------+
