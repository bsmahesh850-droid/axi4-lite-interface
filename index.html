06. Viva-Voce Defense & Technical Interview Guide

High-yield VLSI/RTL engineering questions and detailed answer key for academic defense and job interviews.

Q1: Why choose AXI4-Lite over Memory-Mapped APB or AHB?

AXI4-Lite offers fully decoupled, independent read and write channels using READY/VALID handshakes. Unlike APB (which uses a fixed 2-cycle setup/enable scheme) or AHB (which features shared address/data phases), AXI4-Lite permits simultaneous read and write operations, enabling much higher operational throughput and maximum clock frequency ($F_{max}$).

Q2: How does your Slave design handle unmapped address space?

To prevent bus lockups, the internal address decoder evaluates incoming offsets (`AWADDR`/`ARADDR`). If an out-of-bounds address (e.g., 0x10) is accessed, the slave completes the handshake and responds with error code 2'b11 (DECERR) on `BRESP` or `RRESP`.

Q3: What purpose do write strobes (WSTRB) serve?

`WSTRB[3:0]` enables byte-level write masking on the 32-bit data bus (`WDATA[31:0]`). Each bit of `WSTRB` corresponds to one 8-bit byte lane. This allows the host processor to modify single bytes within a 32-bit register without requiring costly read-modify-write software cycles.

Q4: How do you guarantee setup and hold timing closure?

All handshake control outputs (`AWREADY`, `WREADY`, `BVALID`, `RVALID`) and internal register updates are registered directly in D flip-flops on the rising edge of `S_AXI_ACLK`. This eliminates long combinational logic paths between inputs and outputs.
