AXI4-Lite
Register Interface

A learning-focused RTL system that demonstrates memory-mapped register access, independent channel handshakes, byte writes, response codes, and self-checking simulation.

DATA WIDTH
32-bit

REGISTER BANK
4 × 32

Four memory-mapped read/write registers.

VERIFICATION
8 checks

Planned self-checking cases in the included testbench; run locally to confirm.

Five independent channels

Each transfer happens on a rising clock edge when that channel's VALID and READY are both high. A source must keep VALID and its payload stable until the handshake completes.

Register map

Offsets are byte addresses and must be word-aligned.

OffsetNameAccess
0x00REG0Read/write
0x04REG1Read/write
0x08REG2Read/write
0x0CREG3Read/write

Other addresses return SLVERR. Reset clears all registers.

Explore a response

Select a response code to understand the expected meaning.

OKAY (2'b00)

The register access was accepted. For a read, the returned data should match the selected register's value.

Verification plan

  • Write full word and read it back.
  • Update one byte using WSTRB and preserve other bytes.
  • Access a second register.
  • Check invalid-address SLVERR responses.
  • Use bounded timeouts so a broken handshake fails rather than hanging.
  • Inspect VALID/READY and response timing in the VCD waveform.

Run it locally

Install Icarus Verilog, open a terminal in the repository root, and run:

iverilog -g2012 -Wall -s tb_axi4_lite_system -o simv rtl/axi4_lite_master.v rtl/axi4_lite_slave.v tb/tb_axi4_lite_system.v
vvp simv
gtkwave axi4_lite_system.vcd

Only report PASS after the command actually finishes successfully on your machine.

Engineering scope and next steps

This is an educational single-outstanding master and small register slave, not a certified production AXI IP. The next meaningful extension is randomized READY backpressure and a scoreboard. After the single-master system is verified, add a proper interconnect with address/data routing and response routing—an arbiter that only outputs a grant is not a complete AXI interconnect.
